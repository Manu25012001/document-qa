System Settings & Info

About DocuMind AI

DocuMind AI demonstrates enterprise-grade Retrieval-Augmented Generation (RAG). It indexes PDF documents using vector embeddings and ranks passages with NumPy cosine similarity before prompting Google's Gemini generation model.

Configuration Parameters

Generation Model gemini-3-flash-preview
Embedding Model gemini-embedding-001
Max Document Size 10 MB / 500 Pages
Chunk Size / Overlap 1,200 chars / 150 chars overlap
Similarity Retrieval Top 3 passages (Cosine)
Session Max Questions 30 questions per session

Privacy & Ephemeral Memory

Document vectors and extracted pages are stored in server memory only during your active browser session. No files are permanently written to server storage.
